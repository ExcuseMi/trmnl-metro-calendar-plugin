# style

Reference pictures of the real thing: platform signs, departure boards,
station maps, the tape on a platform edge. Not shipped, not read by any
test or build — they are here to be looked at while the board is being
drawn, so the plugin borrows from signage rather than from screens.

The folder is gitignored. Drop images in, name them for what they show
(`sign-green-line.jpg`, `departures-pudong.jpg`, `map-nyc-legend.png`).

What has been taken from them so far:

- A sign is ONE bar whose sections are butted together and told apart by
  their ground, not a stack of separate boxes with paper between them.
  The foot of the board follows this (rule 2i).
- Sentence case, set bold, not capitals: the Green Line and Spring Street
  signs read at a glance without shouting.
- An icon leads a section, at the type's own height, and every section's
  words start on the same line.
- A route is a filled roundel with the letter knocked out; a station name
  is a box, not a pill (rule 2c).
