# Metro Map & Planning Symbols Guide

Metro maps rely on standard graphic symbols, line conventions, and topological design standards—pioneered by Harry Beck's London Underground map—to communicate complex transit networks clearly. Below is an exhaustive overview of the symbols, lines, connections, and system indicators used in transit design.

---

## 1. Station Symbols

| Symbol / Visual | Name | Description & Meaning |
| :--- | :--- | :--- |
| `●` or `—┬—` | **Standard / Local Stop** | Indicates a regular station served by a single line. Visualized as a solid circle on the line or a tick mark perpendicular to the track. |
| `○` | **Interchange Node** | An open/white circle with a dark border, indicating a transfer point between two or more intersecting lines under a unified station complex. |
| `⬭` or `◎` | **Major Transit Hub** | A capsule/pill shape or concentric circles spanning across multiple parallel lines. Represents large interchanges, central terminals, or multi-line hubs. |
| `◌` (dashed) | **Planned / Infill Station** | A circle with a dashed or faint outline. Represents a station currently under construction, proposed for future expansion, or an infill stop. |
| `█` or `┥` | **Terminal Station** | A thick perpendicular bar or closed end-node indicating the terminus where service ends and trains reverse direction. |
| `♿` | **Accessible Station** | An international symbol of access (wheelchair icon) displayed next to the station name or inside the node, indicating step-free access and elevators. |

---

## 2. Track & Line Conventions

* **Solid Colored Line:** Represents an operational, full-time primary transit line. Distinct colors are assigned to help passengers trace routes across the network.
* **Dashed / Striped Line (`- - -`):** Indicates secondary service, limited-time routes (e.g., peak-hour express runs), or lines under construction.
* **Parallel Dual Lines (`═`):** Used to denote express vs. local track alignments running along the same corridor, or high-capacity multi-track corridors.
* **Bridge / Overpass Curve (`⌒`):** Shows two lines crossing each other visually without a physical track connection or transfer station at the intersection.
* **Branch Point / Y-Fork (`Y`):** Indicates a junction where a primary trunk line splits into multiple operational branches (e.g., Northern Line branches in London).

---

## 3. Connection & Interchange Types

| Interchange Pattern | Visual Representation | Functional Meaning |
| :--- | :--- | :--- |
| **Direct / In-System Interchange** | Touching or overlapping station nodes | Seamless, free transfer between lines inside the paid area without leaving the station complex. |
| **Out-of-Station Interchange (OSI)** | Thin line / dashed barbell connector between distinct nodes (`○---○`) | Requires passengers to exit faregates, walk along street level or a pedestrian tunnel, and re-enter via another station within a specified free transfer window. |
| **Cross-Platform Interchange** | Parallel nodes connected by a short bridge/fill | Passengers can change lines simply by walking across the same platform (same level, adjacent tracks). |
| **Multi-Modal Hub Connector** | Station node paired with modal pictograms | Direct connection to external transport networks. Common icons include: ✈️ (Airport), 🚆 (Regional/High-Speed Rail), 🚌 (Bus Terminal), ⛴️ (Ferry Port). |

---

## 4. Zone & Network Boundaries

```
 +-------------------------------------------------------+
 |                      ZONE 1                           |
 |   (Central Fare District / High-Density Core)        |
 |                                                       |
 |   .................................................   |  <-- Fare Zone Boundary Line
 |                                                       |
 |                      ZONE 2                           |
 |   (Suburban Distants / Higher Fare Tier)             |
 +-------------------------------------------------------+
```

* **Concentric Shading / Tinted Bands:** Background color fills that distinguish tariff regions (Zone 1, Zone 2, etc.) for distance-based or zone-based ticketing.
* **Fare Boundary Line:** A dashed perimeter marking the border where riders transition into a different pricing district.
* **Network Boundary / System End:** Dashed boundaries or grayed-out routes indicating where the main metro system ends and regional rail or suburban networks begin.
